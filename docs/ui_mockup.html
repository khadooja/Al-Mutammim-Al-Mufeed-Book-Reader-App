Design tokens

Forest #1B4D3E — headers, buttons, icon ink
Forest deep #123529 — app-bar title, hero heading
Sage #DCEFE1 — hero card background
Sage soft #EEF7F1 — app bar, icon rings
Ivory #F7F4EC — page background
Gold #B8935B — thin accents, chevrons, icon outlines
  • Headings & the book title use Amiri (serif, manuscript feel). All other UI text uses Tajawal (sans, clean, readable for long content).
  • Chapter icons: thin gold ring instead of a flat fill — keeps the list calm and lets the hero card be the one bold green moment on the page.
  • Cards use 16–22px corner radius, a single 1px hairline border (no heavy drop shadows) to keep the page light and paper-like.
  • RTL throughout — chevrons point left (toward reading direction), icons sit on the trailing (left) edge of each row.
